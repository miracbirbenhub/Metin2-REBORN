# Unity Mobile Client

This directory is the future Unity client root.

## Planned stack

- Unity 6 LTS-compatible project
- C#
- Android first
- iOS after Android vertical slice
- URP/mobile-friendly rendering
- Touch input abstraction
- Authoritative server networking

## First scene

The first scene is the Warrior vertical slice:

1. Load one imported/authorized map
2. Spawn Warrior
3. Follow with third-person camera
4. Move with touch joystick
5. Target one Metin Stone
6. Attack
7. Destroy the Metin Stone
8. Spawn one test drop
9. Pick up the drop

No full MMO systems are required before this loop is stable.
