# Metin2 Reborn — Unity Assets

This project is prepared to import Metin2-compatible assets that the developer is legally authorized to use.

## Target 1:1 content set

- Warrior: body, armor, hair, weapon, skeleton, idle/walk/run/attack/death animations
- Monsters: model, textures, skeleton and combat animations
- Metin Stones: model, textures, hit/damage/death effects
- Maps: terrain/height data, textures, static objects, trees, water and collision
- VFX/UI: hit effects, damage numbers, drops, inventory/equipment icons

## Important

Original proprietary Metin2 assets are not included in this repository. Put only assets you have the right to use here.
